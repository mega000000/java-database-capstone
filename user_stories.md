# User Stories - Smart Clinic Management System

## Admin
1. **As an Admin**, I want to add, update, and remove doctors from the system so that the clinic's staff directory remains accurate and up-to-date.
2. **As an Admin**, I want to view daily appointment reports by doctor so that I can monitor the clinic's workload and patient distribution.
3. **As an Admin**, I want to search and filter doctors by specialty and availability so that I can efficiently manage schedules.

## Doctor
1. **As a Doctor**, I want to view all my upcoming appointments on my dashboard so that I know my schedule for the day.
2. **As a Doctor**, I want to prescribe medications and add consultation notes for a patient so that there is a permanent, flexible record of the treatment.
3. **As a Doctor**, I want to search for patients by name and view their previous prescriptions so that I can make informed decisions for ongoing care.

## Patient
1. **As a Patient**, I want to schedule an appointment with a specific doctor on a chosen date and time so that I can receive a medical consultation.
2. **As a Patient**, I want to view my past prescriptions and doctor notes so that I know exactly what medications I need to take.
3. **As a Patient**, I want to update my contact information (email, address) so that the clinic can reach me reliably.
